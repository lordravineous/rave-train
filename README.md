# 🚂 RAVE TRAIN

Find your friends · build your train · reach the next stage.

A pixel-art snake-with-a-twist set at a music festival. Weave your conga line
of ravers through crowds, grab totem powerups, dodge the flame-breathing art
car, and catch the last shuttle home.

**Play:** open `index.html` in any browser — desktop (arrows / A·D / mouse) or
mobile (touch). No build, no dependencies, one file.

## Controls
- Steer: ← → / A · D / mouse / touch
- M mute · P pause (R restart · Q quit) · ` debug (1-8 jump stage, N next)

## Deploy
Single static file. Works on Cloudflare Pages, GitHub Pages, Netlify, itch.io.
